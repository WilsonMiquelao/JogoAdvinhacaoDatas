# JogoAdvinhacaoDatas
Construi um jogo de adivinhação envolvendo datas históricas.  O intuito do jogo é advinhar a data, e o prompt retorna digito por digito se está correto, dando chances ao usuario ate o acerto. Neste projeto lidei com estrutura de dicionário, arquivos JSON, algumas funções envolvendo estrutura de listas e manipulando variáveis boleanas.
